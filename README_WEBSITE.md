# SmartFarm AI Website

A responsive student project website about smart farming and agriculture awareness.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout and visual design
- `script.js` — interactive topic checklist

## Run locally
Open `index.html` in a browser.

## Upload to GitHub
1. Open your existing `AI-Smart-Farming-Assistant` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` (you can also upload this README).
4. Commit the changes to the `main` branch.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages section.

## Note
This is an educational demo. It does not provide live weather data, sensor readings, or crop-disease diagnosis. Confirm farm decisions with local agricultural experts.
